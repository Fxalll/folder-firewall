# folder-firewall

一个批量管理文件夹下所有 exe 联网权限的 Windows 脚本。

## 功能

- 批量禁止指定文件夹内所有 exe 程序的网络访问（入站+出站）
- 批量恢复指定文件夹内所有 exe 程序的网络访问

## 使用方法

1. 右键点击 `禁网.bat`，选择"以管理员身份运行"
2. 输入要操作的文件夹路径（如 `C:\Program Files\某软件`）
3. 脚本自动为该文件夹下所有 exe 创建防火墙规则

恢复联网同样操作，运行 `解网.bat` 并输入相同文件夹路径。

## 注意事项

- 必须以管理员身份运行
- 规则名称固定为 `blocked [exe路径] via script`，请不要手动修改这些规则
